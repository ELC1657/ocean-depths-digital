# Nautic Discovery

Website for Nautic Discovery — exploring and documenting historical shipwrecks worldwide.

## Tech stack

- Vite
- React + TypeScript
- Tailwind CSS
- shadcn/ui

## Getting started

Requires Node.js 18+ and npm.

```sh
npm install
npm run dev
```

The dev server runs at http://localhost:8080.

## Build

```sh
npm run build
npm run preview
```

The production build is output to `dist/`.
